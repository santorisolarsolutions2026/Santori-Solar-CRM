# Non-Glowing Buttons and Badges Policy

To maintain a professional, high-end corporate SaaS design for the Santori Solar CRM, the following layout rules must be strictly followed for all buttons, badges, and statuses:

1. **No Glowing / Neon Colors**:
   * Never use bright, high-contrast neon borders or text combinations (e.g., bright emerald-green borders, screaming purple, neon red glows).
   * Avoid any glowing ring effects or translucent neon backdrop filters.

2. **Soft, Muted Flat Colors**:
   * Use flat solid backgrounds with low-opacity tints (e.g., `10%` to `15%` background color opacity) paired with high-legibility matching text colors.
   * If borders are used on buttons, they must be subtle, thin, and low-contrast (such as slate or neutral dark outlines like `border-slate-800`).

3. **No Pill Shapes**:
   * Keep corners rounded-md or rounded-lg (rectangular corners). Never use capsule pills (`rounded-full`).

4. **No screaming capitalization**:
   * Always use standard capitalized text (e.g., `Follow Up Scheduled` instead of `FOLLOW UP SCHEDULED`) for a refined typographic tone.
